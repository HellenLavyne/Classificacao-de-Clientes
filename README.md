# Classificação de Clientes - Bom pagador e mal pagador 

O dataset utilizado neste projeto é o _Statlog (German Credit Data)_, um conjunto de dados clássico disponibilizado pelo _UCI Machine Learning Repository_. Ele é amplamente empregado em estudos de aprendizado de máquina voltados à análise de risco de crédito.
O objetivo central é classificar solicitantes de crédito em duas categorias: bom pagador (classe 0) ou mau pagador (classe 1), com base em um conjunto de atributos socioeconômicos e financeiros.
